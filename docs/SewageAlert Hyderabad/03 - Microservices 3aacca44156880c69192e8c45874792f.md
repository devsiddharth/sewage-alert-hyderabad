# 03 - Microservices

## What are Microservices?

<aside>
🧩

Microservices is an architectural approach where an application is divided into independent services. Each service focuses on a single business capability, has its own responsibilities, and communicates with other services using REST APIs.

</aside>

---

## Why Microservices?

<aside>
🧩

- Independent Development
- Easier Maintenance
- Better Scalability
- Fault Isolation
- Faster Deployment
- Clear Business Boundaries
</aside>

## 🔐 Authentication Service

> 🎯 Purpose
> 
> 
> Secure authentication and authorization.
> 

### ⚙️ Responsibilities

- Register Users
- Login
- Generate JWT
- Validate JWT
- Encrypt Passwords

### 📦 Owns

- Users
- Roles

### 🔗 Communicates With

- API Gateway
- User Service
